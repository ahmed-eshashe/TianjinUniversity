# Literature Mining Skill

## When to Use
Use when:
- Conducting comprehensive surveys on deformable object manipulation (DOM), robotic cutting, and vision-tactile RL.
- Updating `literature/taxonomy.md` or adding new paper summaries in `literature/papers/`.
- Generating clean BibTeX entries for `paper/references.bib`.
- Auditing citations for accuracy and authenticity.

## Taxonomy Dimensions
When reviewing cutting and manipulation literature, classify across:
1. **Embodiment**: Single-arm vs Bimanual vs Dexterous Hand.
2. **Material Model**: Rigid proxy vs Spring-mass vs Continuum FEM vs Real food.
3. **Control Paradigm**: Open-loop kinematic vs Classical impedance vs Imitation Learning vs RL.
4. **Perception**: Vision only vs F/T wrench vs GelSight / Optical tactile vs Tactile array skin.
5. **Validation Venue**: Simulation only vs Real robot vs In-the-wild kitchen benchmark.
