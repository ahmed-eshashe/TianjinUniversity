# Tianjin University Master's Research & Development Workspace

Welcome to the central repository for Master's research under Professor Shan An (DEX-ROB Lab, Tianjin University).

## Directory Structure

- `research/`
  - `proposals/`: Formal thesis and project proposals presented to advisor/lab.
  - `literature_survey/`: Comprehensive reviews, state-of-the-art analyses, and taxonomies.
  - `directions/`: Brainstorming, formulations, hardware/software co-design documents.
  - `architectures/`: Detailed perception, hardware, and control system design specs.
- `src/` (Future): Code for vision-tactile pipelines, ROS 2 nodes, and simulation environments.
- `hardware/` (Future): CAD, rigid-flex PCB schematics (Altium Designer), and BOM files.
