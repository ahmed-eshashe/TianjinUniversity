Controller-only tomato cutting tests

Read REPORT.txt for all 11 runs and limitations. recommended_motion.json contains the recommended exploratory motion. compare.py reproduces runs with --cases NAME --dt .0001 --suffix UNIQUE_SUFFIX; each output directory must be new. summarize.py builds the report from saved results.

The original material, blade, solver, fixed fixture and all safety limits were imported unchanged. No changes were made to the open Isaac viewer or the original robot/kitchen/DiSECt setup. The recommended controller has not replaced the existing demo.
