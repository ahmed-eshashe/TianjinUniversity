Precision controls on the five originally discrepant face-center samples:
- An independent float64 closest-point calculation on float32-rounded mesh/query coordinates produced distances no larger than 0.000155 micrometres. Coordinate rounding alone therefore does not account for the measured multi-micrometre errors at these points.
- Reproducing the installed interior-branch formula in host float32 showed strong cancellation and unstable barycentric values, especially on face 92. The host error there was about 695 micrometres; the native global mesh query found a different, closer face and reported about 52 micrometres.
- Using float64 for that host formula returned distances below 0.000000436 micrometres across those five face centers.
- Host NumPy evaluation and GPU fused arithmetic can differ. These controls support the numerical-conditioning explanation; they do not reproduce the native GPU instruction stream or prove every error has the same cause.
