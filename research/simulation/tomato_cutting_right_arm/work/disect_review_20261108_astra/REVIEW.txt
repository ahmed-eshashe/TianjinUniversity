Assessment: keep3/4 scoped numerical checks; do not accept the speed check. Before further solver development, require a concrete feasibility decision and a bounded performance target tied to the actual contact/cutting workload.

FINDINGS THAT SHOULD DRIVE THE NEXT DECISION
1. HIGH — The candidate is now a custom solver whose cutting layer is missing.
   backend/numerics.py disables gradients; the active blade adapter loads the intact mesh. The conforming split and47-patch mapping are offline files. No full-cut timing or detached-piece result exists. The official DiSECt method couples FEM with cut-plane springs, contact and damage; the current custom bulk implementation has not reproduced that full capability. Label it an experimental DiSECt-derived forward solver, not an adopted DiSECt cutting backend.
   Lack of autodiff does not itself prevent ordinary RL or imitation. It does prevent claiming the paper's differentiable optimization capability has been retained. This distinction matters to later learning plans.

2. HIGH — Mass conservation has come with potentially severe small-cell costs.
   The split's minimum nodal mass is4.5978e-13kg versus6.5275e-8kg before splitting: about141,970 times smaller.141 cells have volumes below1e-13m3. This does not prove instability, but invalidates any assumption that intact-mesh timesteps/cost carry over. Evaluate quality and an appropriate timestep bound before a long assembled hold. Do not alter masses or delete cells to manufacture a pass.
   The original-patch transfer samples231 used source points and directly touches301 of604 interface nodes on each side. That count alone does not prove an unstable mode, since bulk elasticity couples nodes. It does show that constant-gap energy checks cannot establish nonuniform interface restraint; independent nonuniform patch/closure tests are needed if this mapping is adopted.

3. HIGH — The contact evidence is a two-node microscopic probe.
   The prescribed downward stroke is60micrometres, with at most two active exterior nodes and peak resultant about0.953mN. This is useful as a contact smoke test, not representative cutting-load validation. Fixed per-node penalties and no area quadrature make changes in surface sampling a model concern. Surface-node-only contact also cannot guarantee collision coverage between nodes. Retaining the exact CAD triangles does not remove those limitations.
   The adapter copies full position/velocity arrays from GPU to host and returns forces to GPU each tiny step. This is a visible performance concern, but no exact share of runtime is assigned without profiling.

4. MEDIUM — Force refinement failure is localized and should be diagnosed precisely.
   Independently reproduced worst vector discrepancy:10.0822% at8ms; absolute discrepancy7.93996e-5N. Both runs go from one active node at7.5ms to two at8ms. Peaks are0.952762 and0.955663mN, only about0.30% apart. This is evidence consistent with contact-onset/discretization sensitivity, not proof of its cause. The original5% gate still fails. A focused event-resolution/convergence check, if authorized as the next bounded task, is more justified than arbitrary damping/material changes.
   Actual coarse probe runtime is82.824s for0.045 simulated seconds:1840.5 wall s/s, or30.7minutes per simulated second. Half-step probe:3345.2 wall s/s, or55.8minutes. These are measured averages of the short probe, not predictions of a full cut. The previous13–22minute statement described unloaded holds and understated the contact workload's observed cost.

5. MEDIUM — The viscosity model still resists rigid rotation.
   The retained Fdot damping produces nonzero resistance under pure rigid-spin velocity. Algebraic audit at1rad/s gives force norm0.00202977N, dissipated power0.00242507W and opposing torque0.00242507Nm. This is not a new failure of the corrected elastic invariant; it is a known class of limitation of the retained viscous model. Do not call the whole constitutive model rotation-objective. Decide whether that damping model is acceptable for the research task before generalizing learned paths; changing it would be a model decision, not a numerical tweak.

SEPARATION-EVALUATOR NOTE
The inspected upstream cut-spring force retains a kd*dcdt term when ke reaches zero. The actual prism configuration uses kd=0, so this is NOT an additional hidden bridge in those reported example runs. If future settings use nonzero spring damping, the evaluator must account for it. Zero elastic stiffness alone is not universally equivalent to no cross-cut material force. Intended unilateral cut-face collision should be distinguished from tensile/material connections.
